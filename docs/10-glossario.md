# 10 – Glossário

| Termo | Significado |
|---|---|
| **CBS** | Contribuição sobre Bens e Serviços (federal). Substitui PIS/COFINS |
| **IBS** | Imposto sobre Bens e Serviços (estadual + municipal). Substitui ICMS/ISS |
| **IS** | Imposto Seletivo, sobre bens prejudiciais à saúde ou ao meio ambiente |
| **LC 214/2025** | Lei Complementar que regulamenta a reforma do consumo |
| **NT** | Nota Técnica do Portal Nacional da NF-e (ex.: 2025.002 IBS/CBS; 2026.005 Simples Nacional) |
| **NF-e / NFC-e** | Nota Fiscal Eletrônica (mod. 55, venda a empresas) / de Consumidor (mod. 65, varejo) |
| **NFS-e** | Nota Fiscal de Serviço eletrônica (padrão nacional via nfse.gov.br) |
| **DANFE / DANFSe** | Documento auxiliar impresso (PDF) da NF-e/NFC-e / da NFS-e |
| **SEFAZ** | Secretaria da Fazenda estadual, que autoriza NF-e/NFC-e |
| **SVRS / SVAN** | SEFAZ Virtual do RS / do Ambiente Nacional, que autorizam por estados sem webservice próprio |
| **Homologação** | Ambiente de testes da SEFAZ (notas sem valor fiscal) |
| **Certificado A1** | Certificado digital ICP-Brasil em arquivo (.pfx), válido por 1 ano |
| **CSC / ID Token** | Código de Segurança do Contribuinte, usado no QR Code da NFC-e |
| **CSRT / infRespTec** | Código e grupo de identificação do responsável técnico pelo software emissor |
| **cStat / xMotivo** | Código e texto de retorno da SEFAZ (100 = autorizado) |
| **tpEmis** | Tipo de emissão (1 normal, 9 contingência offline NFC-e) |
| **CRT** | Código de Regime Tributário: 1 SN, 2 SN excesso de sublimite, 3 Normal, 4 MEI |
| **CSOSN** | Código de Situação da Operação no Simples Nacional (ICMS) |
| **CST (IBS/CBS)** | Código de Situação Tributária da reforma (ex. 000 tributação integral, 200 redução) |
| **cClassTrib** | Código de Classificação Tributária do IBS/CBS (6 dígitos) |
| **NCM / NBS / CEST** | Nomenclaturas de mercadorias / serviços / substituição tributária |
| **cAtivSN** | Código de atividade do Simples Nacional na calculadora (ex. 01 revenda) |
| **pIBSSN / pCBSSN** | Alíquotas efetivas do Simples para IBS/CBS (informadas, não calculadas pela API) |
| **tpRegimeIBSCBS** | Regime de apuração do IBS/CBS do optante (NT 2026.005) |
| **RBT12** | Receita bruta dos últimos 12 meses (define a faixa do Simples) |
| **RLS** | Row Level Security (Postgres), isolamento entre empresas |
| **Modo hoje / 2033** | Os dois cálculos do NotaLeve: o da nota vigente e a simulação da reforma completa |
