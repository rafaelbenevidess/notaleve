# ADR-0010 — Nome do produto: NotaLeve
- **Status:** aceito (provisório) · **Data:** 2026-11-17

## Decisão
O usuário delegou a escolha do nome. "NotaLeve" (nota fiscal + leveza) comunica simplicidade para o lojista. O repositório se chama `notaleve`.

## Pendências
Busca de marca no INPI e de domínio antes do lançamento (P-10).
